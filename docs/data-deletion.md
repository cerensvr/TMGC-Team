# SkinShelf Data Deletion

Last updated: 2026-07-12

Users can permanently delete their account directly from the application.

Steps:

1. Open Profile.
2. Tap **"Hesabı ve Verileri Sil"**.
3. Confirm the deletion.

This permanently removes:

- User account
- Skin profile
- Shelf products
- Assistant chat history
- Skin tracking logs

from the backend database.

Skin photos are not stored by default and therefore do not require separate deletion.

This page may also be used as the public Data Deletion URL for app store listings.
