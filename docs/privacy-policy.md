# SkinShelf Privacy Policy

Last updated: 2026-07-30

SkinShelf stores the account information, skin profile, shelf products, routines, assistant chat history, and skin tracking logs required to provide personalized skincare features.

SkinShelf uses Google Gemini AI to generate personalized skincare recommendations, analyze skin photos, and assist users through the Shelly AI Assistant. Skin photos are processed only for analysis purposes and are not stored by default. The application stores the generated analysis results and related form responses instead of the original image files.

Product information may be retrieved from the Open Beauty Facts API using barcode lookups. User data is securely stored in a Supabase PostgreSQL database.

Users can delete their account at any time from the Profile screen. Account deletion removes the user account and all related personal data, including skin profile, products, assistant messages, routines, and skin tracking records from the backend database.

SkinShelf is not a medical device and does not provide medical diagnosis. All AI-generated recommendations and analyses are provided for informational purposes only and should not replace professional medical advice.
