## Kolon Tanımları

| Kolon | Definition of Ready / Done |
| --- | --- |
| Product Backlog | Ürün fikri var; henüz sprint hedefine alınmamış. |
| To Do | Kabul kriteri, point ve assignee tanımlı. |
| Progress | Uygulama veya kanıt çalışması devam ediyor. |
| Review | Kod/test hazır; ekip veya teslim kanıtı kontrol ediliyor. |
| Done | Kabul kriterleri geçti, kanıt linklendi ve issue kapandı. |

## Kart Alanları

Sprint 3 kartlarında aşağıdaki alanlar aynı anlamla kullanılmalıdır:

| Alan | Kullanım |
| --- | --- |
| `Status` | Product Backlog, To Do, Progress, Review, Done |
| `Sprint` | Sprint 3 |
| `Point` | Issue başlığıyla aynı SP değeri |
| `Assignee` | Issue sorumlusu |
| `Priority` | P0 veya P1 |
| `Evidence` | Test, ekran, build veya doküman linki |

Kart adlarının yalnızca `5`, `8`, `13` gibi puanlardan oluşmaması gerekir.
Point değeri kart başlığı değil, `Point` property alanında tutulur.
